# Content Rating — Play Console questionnaire guide

The content rating comes from the IARC questionnaire in Play Console. Answer
these categories as follows for an honest, accurate rating.

| Category | Answer | Why |
|---|---|---|
| Violence | None | No fighting, weapons, or injury depicted |
| Sexual content | None | No sexual or suggestive content |
| Profanity / crude language | None (or "Mild crude humor" if that option appears) | The roasts are playful "your mom" jokes, not profanity |
| Gambling | No | No real-money or simulated gambling |
| Drugs / alcohol / tobacco | None | No references |
| User interaction / user-generated content | None | Single-player, no chat, no UGC |
| Shares location | No | No location access |
| Shares personal info | No | No accounts or personal data |

**Expected result:** Everyone (ESRB "E" / PEGI 3).

### Notes

- If the questionnaire forces a "Mild crude humor" descriptor for the
  "maică-ta" jokes, the result may bump to **Everyone 10+** — that is still
  accurate and fine.
- There is no profanity in the UI text (English) or in the Romanian roast
  lines, so you can confidently answer "No" to profanity.
